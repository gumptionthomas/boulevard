# Milestone 5 — Polish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the software say the right things, at sizes matched to their consequence, with controls placed so a destructive one is never a mis-tap away from a benign one.

**Architecture:** No routes, no schema, no behaviour. Three systems land first — a type scale with a consequence class, a control-placement rule, and a vocabulary — then every user-facing string is read once against them.

**Tech Stack:** Go 1.26, `html/template` behind `go:embed` with CSS inlined in `layout.html`, `github.com/go-pdf/fpdf` for the booklet.

**Spec:** `docs/superpowers/specs/2026-08-23-polish-design.md` — read it before Task 1. It carries the reasoning, and two of its decisions correct `DESIGN.md` itself.

## Global Constraints

- **"The shelf" is one word for the digital list and the physical spot.** A reader meets "the shelf is empty" and "scan the card at the shelf" on the same page; that is intended.
- **The two artifacts are the shelf code** (mounted, permanent, browses) **and the take/leave card** (placed close, monthly, grants a session).
- **Banned from user-facing copy:** "the box", "box door", "Little Free Library", and anything LFL-specific such as "the hinge".
- **No copy claims a scan distance.** The two QR codes are 1.5in and 1.15in — both up-close. Milestone 5.5 makes a distance claim true; until then artifacts are distinguished by what they do. This bans "from the sidewalk" and "from a distance".
- **Terse.** Write it, delete the second sentence, check it still works.
- **Tests that assert copy get their expected strings UPDATED, never relaxed.** Loosening an assertion so it stops caring is a defect, not a fix.
- **The generic failure page must stay byte-identical for an unknown secret and a revoked one.** Its copy may change; the two cases may not diverge.
- `go vet ./...` and `gofmt -l .` clean before every commit. Run the whole suite (`go test ./...`); it is fast.
- This codebase comments the *why*, not the *what*, at length.

### Task 6: The vocabulary guard

**Files:**
- Create: `internal/web/vocabulary_test.go`

**Interfaces:** consumes `templateFS` from `internal/web/server.go`.

- [ ] **Step 1: Write the test**

```go
package web

import (
	"io/fs"
	"strings"
	"testing"
)

// No user-facing template may assume a Little Free Library.
//
// An LFL is one demographic. A Boulevard may be a sandwich board, a garage
// door, or a fence, and copy that says "the box" or "inside the box door"
// excludes every steward who has none of those. This guards the vocabulary
// against a future page quietly reintroducing it — the sweep that removed
// it touched nineteen templates, and the twentieth is the one nobody
// remembers.
//
// "from the sidewalk" and "from a distance" are banned for a different
// reason: the two printed codes are 1.5in and 1.15in, both readable only up
// close, so a distance claim describes an artifact that does not exist yet.
// Milestone 5.5 makes it true. Until then, saying it would be a lie in
// print.
func TestNoTemplateAssumesALittleFreeLibrary(t *testing.T) {
	banned := []string{
		"the box",
		"box door",
		"Little Free Library",
		"the hinge",
		"from the sidewalk",
		"from a distance",
	}

	err := fs.WalkDir(templateFS, ".", func(path string, d fs.DirEntry, err error) error {
		if err != nil || d.IsDir() {
			return err
		}
		b, readErr := templateFS.ReadFile(path)
		if readErr != nil {
			return readErr
		}
		lower := strings.ToLower(string(b))
		for _, phrase := range banned {
			if strings.Contains(lower, strings.ToLower(phrase)) {
				t.Errorf("%s contains %q — a Boulevard may be a garage door, not a box", path, phrase)
			}
		}
		return nil
	})
	if err != nil {
		t.Fatalf("walk templates: %v", err)
	}
}
```

Run: `go test -run TestNoTemplateAssumesALittleFreeLibrary ./internal/web`

### Task 7: The orientation line

**The line:** `Things people leave for each other.`

It sits under the library name, above the items, **unconditionally** — whether or not the reader holds a session.

Session state is not a proxy for understanding. Someone may scan the take/leave card *precisely because* they are working out what this is; that scan mints a session, and hiding the explanation from them hides it from exactly the person asking.

- [ ] **Step 1: Write the failing test**

// Orientation is unconditional: session or not, empty or stocked.
//
// A stocked shelf shows notes and links but never says what the thing is,
// so a reader arriving from a shared link is exactly as lost as at an empty
// one. And a session does not mean the reader understands — scanning the
// card is often how someone asks what this is.
func TestShelfAlwaysSaysWhatItIs(t *testing.T) {
	const orientation = "Things people leave for each other."

	for _, tc := range []struct{ name string; stocked, session bool }{
		{"empty, no session", false, false},
		{"empty, with session", false, true},
		{"stocked, no session", true, false},
		{"stocked, with session", true, true},

		t.Run(tc.name, func(t *testing.T) {
			st := testStore(t)

## Notes for the executor

**Copy is the deliverable here, not code.** A diff of templates does not read as prose, so every task that changes wording asks you to report the before and after. The reviewer is judging sentences.

**The one failure mode this plan is built against:** a copy sweep breaks tests that assert old strings, and the cheap fix is to loosen the assertion until it stops caring. Every such test gets its expected string rewritten. If loosening feels necessary, the copy is probably wrong.

**Verified against the repository on 23 August 2026:** `templateFS` (`internal/web/server.go`), `stewardServer`, `seedWebTokens`, `loginAsSteward`, `getWithCookie`, `testStore`, `addLibrary`, `get` (`internal/web`), and the exact file:line locations named in Tasks 3 and 5. Task 7's two fixture helpers are **not** verified — find the existing equivalents rather than writing new ones.

**Two things must not change:** the generic failure page stays byte-identical between an unknown secret and a revoked one (its copy may change; the two cases may not diverge), and no user-facing string claims a scan distance until Milestone 5.5 makes one true.

**Three things are deliberately out of scope**, so that finding them does not read as an invitation:

- **Cold-cellular performance.** Already satisfied by construction — no JavaScript, no images, no external requests, CSS inlined. The remaining win is compression, which belongs to the reverse proxy §8 already assumes for TLS. Do not add gzip here.
- **The shelf code's geometry.** Milestone 5.5. This plan changes what the cover *says* about it, never its size.
- **`boulevard booklet` reprint requiring `--base-url`.** A real hazard, recorded during the Milestone 4b acceptance run, and a CLI flag change rather than look-and-feel.
